# Names for the official Instagram API switch (working note — delete after the docs are updated)

Source of truth: docs/INSTAGRAM-INTEGRATION.md. Use exactly these names everywhere.

## Removed from the whole plan
`instagrapi`, password login, challenge codes, two-factor, per-account proxies, request pacing, `ResearchConnection`, `ig_research_login`, `InstagramResearchProvider`, `SOCIALHUB_IG_REQUIRE_PROXY`, `SOCIALHUB_IG_PACING_SECONDS`, all `SOCIALHUB_IG_RESEARCH_*` settings, `media_pk_from_code`, provider errors `SessionRequired`, `ChallengeRequired`, `ProxyError`, `AccountRestricted`, connection status `challenge_required`, `AccountConnection.challenge` / `session_encrypted` / `proxy_url_encrypted`, endpoints `POST /accounts/{id}/connection/login/` and `/challenge/`, job kinds `instagram.login` and `instagram.challenge`, API error codes `instagram_session_required` and `instagram_challenge_required`, Publication `blocked_reason = session_problem`.

## AccountConnection (DATA-MODEL)
`provider` (`graph_api`, `manual`, `fake`) · `status` (`disconnected`, `connected`, `expiring`, `needs_attention`) · `ig_user_id` · `username` · `account_type` (`BUSINESS`, `MEDIA_CREATOR`) · `access_token_encrypted` (never serialized) · `token_expires_at` · `token_refreshed_at` · `scopes` (JSON list) · `capabilities` (`publish_feed`, `publish_reel`, `publish_story`, `insights`; no `research`) · `last_verified_at` · `last_error_code` / `last_error_at`.

## Publication / PublishAttempt (DATA-MODEL)
Publication adds `remote_container_id` (text, null), `container_status` (`IN_PROGRESS`, `FINISHED`, `ERROR`, `EXPIRED`, `PUBLISHED`, null), `container_created_at`; renames `remote_media_pk` → `remote_media_id`, `remote_media_code` → `remote_shortcode`; keeps `permalink`, `caption_fingerprint`. `blocked_reason`: `publishing_paused`, `connection_problem`, `daily_limit`. PublishAttempt `verification.checks[].method`: `container_status`, `media_list`, `active_stories`.

## Research (DATA-MODEL, E02)
MVP `ResearchSource.kind`: `web_search`, `rss`. `TrendSignal.kind`: `web_search`, `rss`, `manual`. `instagram_hashtag` and `instagram_account` are reserved for E02-S03 (Later, Facebook Login adapter).

## Endpoints (API.md, E00-S04)
- `GET /accounts/{id}/connection/` — status, username, account_type, token_expires_at, scopes, capabilities, has_token (never the token).
- `PATCH /accounts/{id}/connection/` (admin) — `{"provider": "graph_api" | "manual" | "fake"}`; only while `disconnected`; choosing `manual` connects at once with every capability false.
- `POST /accounts/{id}/connection/connect/` (admin) — returns `{"authorize_url", "expires_at"}`; state kept 10 min in Redis.
- `GET /instagram/oauth/callback/` (public) — finishes OAuth synchronously and redirects the browser to `/settings/accounts/{id}?tab=connection&connect=success` or `&connect=error&code={code}`.
- `POST /accounts/{id}/connection/verify/` — job `instagram.verify`.
- `POST /accounts/{id}/connection/refresh-token/` (admin) — job `instagram.refresh_token`.
- `DELETE /accounts/{id}/connection/` (admin) — deletes the token, capabilities false, `publishing_enabled` false.

Connection codes (callback `code` / job `error_code`): `oauth_state_invalid`, `oauth_denied`, `oauth_exchange_failed`, `account_mismatch`, `not_professional`, `permission_missing`, `token_invalid`, `rate_limited`, `provider_error`.

Top-level API error codes: `instagram_not_connected` (409; account not connected or `needs_attention`), `instagram_permission_missing` (409), `publishing_disabled` (409, unchanged).

## Jobs and Beat
Job kinds `instagram.verify`, `instagram.refresh_token`. Beat: `instagram.refresh_tokens` daily 02:15 UTC (tokens with `token_refreshed_at` older than `SOCIALHUB_IG_TOKEN_REFRESH_AFTER_DAYS`, default 7); `instagram.verify_all` daily 03:00 UTC with up to 30 min random delay.

## Provider interface and errors
As in INSTAGRAM-INTEGRATION.md section 7: methods `authorize_url`, `exchange_code`, `refresh_token`, `verify`, `publishing_quota`, `create_container`, `container_status`, `publish_container`, `get_media`, `list_recent_media`, `list_active_stories`, `media_insights`, `account_stats`. Errors `TokenInvalid`, `PermissionMissing`, `RateLimited`, `QuotaExceeded`, `MediaRejected`, `TransientError`, `AmbiguousResult`, `NotFound`, `NotSupported`, `AccountBusy`. Helpers `account_session(account, wait_seconds=60)` (lock `ig:lock:{account_id}`, yields `(provider, token)`), `report_connection_error(account, error)`, `apps.instagram.media.public_url(asset)`.

## Fake provider scenarios
`ok`, `token_invalid`, `permission_missing`, `rate_limited`, `quota_exceeded`, `media_rejected`, `container_slow` (`delay_seconds`), `container_expired`, `timeout_after_publish`, `timeout_before_publish`, `story_timeout_after_publish`, `fail_n_times(n)`, `appears_late` (`delay_seconds`), `values`. Fake OAuth codes: `fake-ok`, `fake-denied`, `fake-mismatch`, `fake-personal`.

## Attention (E11-S01) and status tags (DESIGN-SYSTEM)
Connection tags: `connected` green, `expiring` orange, `needs_attention` orange, `disconnected` grey. Attention types for connections: `connection_needs_attention` (high), `connection_expiring` (medium), `connection_disconnected` (high, only when the account has scheduled publications).
